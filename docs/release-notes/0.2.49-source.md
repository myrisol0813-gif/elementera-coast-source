# 0.2.49-source

## 新增

- Android 空闲首页自动检查正式 GitHub Release，发现新版时显示非模态更新卡片。同一版本在本机只主动提示一次。
- 提示提供「稍后」与「查看更新」，不自动下载安装、不打断聊天，也不消耗模型额度。

## 更新方式

- 已安装正式签名开源 APK 的用户可在「版本与更新」覆盖安装。下载后仍核验 SHA-256、包名、版本号与签名。
- 参观模式不主动显示更新卡片；离线检查失败不弹报错。应用前台约每 15 分钟重新检查。
- 本版只包含更新提示补丁，不包含尚未合并的自主唤醒、休憩箱与聊天优化施工。
- 旧的临时 QA 签名 APK 不能覆盖安装正式签名版本；保留原应用及资料，先确认备份或迁移。
