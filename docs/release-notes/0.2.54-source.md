# 0.2.54-source

## 自主唤醒：重新排程与执行诊断

- 修改每日唤醒时间或时区后，当日的新时间可以触发独立排程；重复保存同一时间或修改预算不会重复触发。
- 区分领取任务、准备上下文、请求模型、执行工具、记录步骤和完成回执，显示安全脱敏的错误原因及用量。
- 保留已完成工具结果；中断时显示部分完成，不自动重放可能已有副作用的工具。
- 活动详情可查看、复制诊断，运行期间 Android 页面定时刷新。
- 在线端保留心跳和过期恢复；本机与在线分别执行，不迁移凭据或改变签名、包名及存储归属。

## 验收

覆盖安装后验证同日改时、前台与锁屏唤醒、工具部分成功及失败诊断。Android 调度受系统省电和 WorkManager 调度影响，不保证秒级准时；真实设备及供应商链路仍须验收。
