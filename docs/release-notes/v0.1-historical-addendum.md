## Historical update (2026-10-22)

**This is the first tagged MIT source milestone, not the current Android build.** Its original APK, code snapshot, and feature list are preserved exactly as released in September 2026.

For the newer implementation and 0.2.2-source temporary Android QA artifacts, see this repository's **current README**, **Releases** tab, and `docs/SOURCE_RELEASE_HISTORY.md`. A temporary QA APK may remain downloadable after its test backend has expired; it is not a stable self-hosted deployment.
