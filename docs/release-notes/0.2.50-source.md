# 0.2.50-source

## 聊天与窗口

- 增加可编辑的窗口工具工作区注入词、分隔气泡设置和表情包显示尺寸；保留表情包原件。
- 完善聊天显示、附件与语音交互、上下文处理以及离线归档呈现，保留已有窗口和原始资料。
- 延续上一版空闲首页的非模态更新提示及正式 APK 的下载、哈希与签名校验。

## 造物间与日历

- 增加独立美术造物间：三间房、动物外观编辑、家具布置、色槽配饰及动作预览；支持本设备保存与独立 JSON 导入导出。当前不连接真实模型休憩、便签或互动事件。
- 日历新增全部记录总览，包含跨年日程、随记及未置顶纪念日，可分类筛选并编辑原记录。每年重复的记录仅在总览中显示一条。

## 自主唤醒

- 增加窗口级自主活动配置、活动历史、独立授权与归档契约。常规本机和套餐本机自动执行均默认关闭；套餐后台自动调用不作为本版已开放功能。
- 配置迁移不恢复自动授权，不以普通聊天记录冒充自主活动，不默认发送未经授权的设备信息。

## 更新

- Android versionCode 52；PWA 主缓存版本 44。沿用现有应用包名与正式签名更新链，不自动安装。
- 造物间布局 JSON 与完整资料归档是不同入口，请分别保存所需备份。
