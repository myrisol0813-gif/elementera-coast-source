# 0.2.53-source

- Adds opt-in device-executed autonomous wake for self-hosted online mode, while retaining the existing local mode.
- Android can use its locally authorized model account to execute eligible online wake activities and write results back to the configured server.
- Includes online wake authorization, activity and notification handling; the server gate must be enabled by the self-host operator. See [deployment guidance](../DREAM_TIDE_DEPLOYMENT.md).
- Model-account credentials stay on the device; visitor isolation remains in place.
- Background execution depends on Android scheduling, battery settings, network access and model availability; exact wake timing is not guaranteed. Existing local wake settings remain available.
- This release does not include the separate Web appearance redesign or custom themes.
