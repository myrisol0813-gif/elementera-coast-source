# Tideloom / 织潮 使用说明

页面顶栏的问号可随时打开功能说明。

## 选择运行方式

- 本机模式：资料保存在手机，可直接连接模型供应商。断网时仍可查看已保存的内容。
- 前后端模式：资料保存在自己的后端，连接同一后端的设备可共享记录。
- 两种模式可通过 ZIP 归档迁移资料。远程模型生成需要网络。

## 记忆库

保存相处中形成的长期记忆。可手动添加，也可确认模型提出的记忆候选，供后续对话使用。

对话 → 记忆候选 → 确认 → 正式记忆

本机开启思维壤整理后，可使用当前选中的模型生成候选。

## 种子库

保存值得继续生长的意象、认知与灵感。添加内容及使用时机，为未来对话提供线索。

## 用户画像

保存模型对用户逐渐形成的长期认识。开启自动整理后，可确认模型提出的修改建议，更新正式正文。

本机开启思维壤整理后，可使用当前选中的模型生成候选。

## 自我画像

保存模型对自身逐渐形成的认识。开启自动整理后，可确认模型提出的修改建议，更新正式正文。

本机开启思维壤整理后，可使用当前选中的模型生成候选。

## 自定义指令

填写希望模型长期参考的背景、表达方式与要求，保存后随对话上下文递入模型。

## 待确认区

查看模型提出的长期资料整理建议，可确认、编辑后确认或驳回。

## 世界书 / 词典

保存人物、地点、专有名词与背景设定。添加词条，设置关键词及适用范围；命中关键词或启用常驻时，可将对应内容递给模型。

添加词条 → 匹配或常驻 → 递入上下文

停用保留词条，可再次启用；永久删除只移除所选词条，须再次确认。记忆库与种子库的删除同样需要确认。已有聊天与旧备份不会被这些操作清除。

## 思维壤

保存当前窗口中需要继续承接的内容。开启自动整理后，每轮整理纸条，供下一轮使用。

当前对话 → 整理纸条 → 下一轮上下文

本机开启后使用当前选中的模型整理。关闭时保留旧纸条，暂停整理和递入。

## 本轮桌面

查看本轮实际递入的上下文与回执，了解模型读取了哪些资料。

## 模型箱

配置与选择用于对话的模型。本机可连接支持的 ChatGPT 账户通道，或填写兼容供应商的 HTTPS API 地址、Key 与模型 ID。前后端模式使用已部署后端提供的模型。

连接供应商 → 选择模型 → 发送消息

模型箱分聊天、生图、语音；生图目录支持分类与搜索，语音需独立配置。额度与费用由供应商决定，Key 不随归档导出。

## 日历与纪念日

记录日常事件与纪念日。新建纪念日时填写标题、起始日期和计算方式；开启侧栏展示即可在侧栏查看及编辑。起始日算第 1 天。点击「全部记录」可查看跨月份、跨年份的原始记录。

## 小组件

记录日常片段，可进入碳硅圈、日记或日历查看及编辑。

## 休憩箱

小组件 → 休憩箱：目前只保留空页入口，没有养成或布置功能。旧造物间已退役；若曾导出房间或形象资料，请保留原始备份，新版本不再采集或恢复该功能的存档。

## 碳硅圈

分享日常、照片与随手写下的想法，保存生活中的片段。

## 日记

记录每天的经历、感受与思考，随时按日期回看。

## 文件库与拾潮

基本文件库：归集聊天中的图片、语音与附件，可分类查看和返回来源。

拾潮：收藏文字与媒体，可添加备注、搜索或取消收藏。取消收藏会保留原聊天内容。

## 潮中书房

导入 EPUB / TXT，点开书籍进入阅读档案，查看双方记录及笔迹，继续阅读或查看目录。支持划线、批注、读后感和原文跳转；暂不支持 PDF。删除整本书也会删除关联笔记。

## 聊天记录与迁移

导出：生成可恢复的 ZIP 归档，用于备份与迁移。

导出 HTML：生成阅读副本。

导入：选择归档，预览并确认需要恢复的资料。

卸载前请将本机归档保存到应用外目录。密钥及登录凭据需单独配置。完整 ZIP 的设备基本设置可按预览单独恢复；HTML 是阅读副本，不是可恢复归档。

## 版本与更新

正常更新请通过屋主设置 → 版本与更新，或从正式官网获取签名 APK；核验包名、版本、SHA-256 和签名后覆盖安装，无需卸载。新版本提醒仅在空白聊天主页且不影响正常操作时出现。

## 屋主设置

管理外观、个人资料、模型配置、聊天记录与应用设置。可通过账户页面返回开屏，切换本机或前后端模式；两种模式分别保存资料。

## 模型工作台 / MCP 工具

配置并启用工具后，支持工具调用的模型可按需读取资料或执行操作。执行结果可在工具记录中查看。

启用工具 → 模型调用 → 执行 → 返回结果

本机可在「这个窗口」分别开启模型读取与写入工具。读取支持记忆、世界书、日历、碳硅圈、日记、书房与拾潮；写入支持新增动态、日记、日历事项、书房笔记及待确认记忆，以及评论和点赞。外部连接尚未接入。

## 主聊天室

与 API 模型日常对话的空间。选择模型后即可聊天。

右上角 ···
现实上下文：递入已启用的设备现场信息。
短句模式：闲聊时优先简短回复。
真实连续回复：允许模型在一组预算内主动追加独立消息，默认关闭。
整理当前对话的纸条：每轮整理，为下一轮提供语境。
登岛信：补充当前窗口的初始背景。

屋主抽屉
私人草稿：补充此刻的心情与想法。
跨窗口选取：将指定旧消息递入本轮。
历史消息搜索：按关键词寻找过去的对话。

本机可在「这个窗口」开启跨窗口回忆，模型按需检索并精读；手动选取仅本轮有效。

## 工具箱注入词

聊天右上角 ··· → 这个窗口 → 工作区：可编辑、保存或恢复当前窗口的工具箱邀请词。默认文案鼓励模型自主选择已经获授权的工具，不要求每轮调用。留空只取消邀请词，不关闭工具。实际权限、预算与确认机制不变；上下文预算不足时邀请词可能不递入，以历史桌面回执为准。

## 分隔气泡与表情包尺寸

聊天右上角 ··· → 这个窗口：分隔气泡默认关闭，模型自主决定同一条正式回复的显示断点，不增加模型请求次数，与真实连续回复可同时使用。分隔气泡共享头像、时间及消息操作；关闭后不要求新回复分隔，已保存的分隔仍可显示。表情包显示尺寸可在同一窗口调整（64—256，默认144）；普通图片和原始文件不受影响。

## 真实连续回复

聊天右上角 ··· → 这个窗口 → 真实连续回复。默认关闭，仅当前窗口生效。开启后，一次发送可由模型自行决定是否继续产生独立消息，不是把长文机械切段。单组回复上限 1—20 条、累计工具预算 0—128 次、累计 token 预算 1—1000000；本窗口留空继承屋主设置 → 基本设置 → 连续回复预算，修改后保存。停止或达到预算时不再追加，已保存消息保留。开启纸条自动整理时，在整组结束后整理一次。普通 API 与 Android 已授权套餐均可尝试；在线需更新服务端。套餐 token 为软预算，单次可能超额，缺少实际用量则停止追加，不等于费用上限。套餐连续回复不使用供应商内置搜索，已授权的应用工具仍可使用。

网页端仅支持普通 API。连续回复不保证每次都有多条消息；本机套餐前序图片回读和纯媒体回复的纸条整理仍需验收。短句模式与连续回复是独立开关。

## 自主唤醒

自主唤醒：在当前窗口设置中打开，绑定模型、时区和每日固定时间，可允许额外预约，设置独立预算及工具权限。保存设置不等于授权；只有明确同意调用费用并保存授权后才会尝试运行。自主手记可查看与回复，活动记录可核对实际结果。撤回授权可停止后续调度。Android 本机依赖系统后台调度，强停、关机、断网及省电可能中断或延迟；在线需部署调度服务，未开通时仅保存配置。套餐需独立授权，token 为软预算；生图和语音可能另收费。网页端不执行设备套餐调用。

本机系统通知：在唤醒设置内分别开启新手记、失败或中断、开始活动通知；使用系统通知类别调整铃声、震动、顶部弹条与锁屏显示。锁屏默认不公开正文；测试通知不请求模型。系统通知权限、勿扰模式及厂商限制可能影响显示。在线模式尚无远程推送。

自主唤醒独立于聊天的连续回复，不保证精确准点，也不保证模型每次都留下手记。网页在线执行需服务器部署；本机配置与授权不会自动上传到服务器。未授权时不会仅因保存设置而启动调用。

## 表情包

聊天右上角 ··· → 这个窗口：分别开启「允许发送表情包」和「允许添加表情包」。发送使用已经登记且启用的素材，不调用生图 API；添加用于登记模型在当前窗口生成并保存的图片。是否发送由模型决定，工具需获授权。 本机发送还需开启本机模型工具与写入权限，添加还需写入权限。

## 共通聊天室

GPT 官端与海岸 API 模型的共通对话区。连接 MCP 后，可在官端与海岸之间继续对话。

如无需要，可忽略。

本机暂不支持官端 MCP 连接。

## MCP 对话区

与 GPT 官端通过 MCP 交换消息的对话区。在此发送消息，由官端读取并回复。

如无需要，可忽略。

本机暂不支持官端 MCP 连接。
