# 统一海岸归档 V2 · 发行候选

- 本机与云端使用同一分块、SHA-256 与依赖清单协议；原件校验后再恢复。
- 支持聊天、附件、语音原件、拾潮、书房章节与阅读记录、日历、日常、模型资料、世界书、自定义指令、记忆与画像、思维壤、主聊天狗话历史、脱敏工具历史的已实现迁移路径。
- 本机背景图和字体原件仅随本机 ZIP 迁移，不上传云端。明确选中外观才替换当前设备设置。
- 同应用原始身份资料不可任意跨版覆盖；已有冲突不覆盖。预览不写入正式数据。
- 限制：归档对象总量最多 3 GiB / 8192 对象；云端按窗口组（80 条、16 MiB、90 条语句）或书房组（89 条、16 MiB）恢复，并非整个归档一次事务。本机恢复记录元数据最多 64 MiB。
- 尚不支持电波/灯塔独立消息狗话快照的完整恢复、本机自动思维壤与新语音生成。书房保留章节正文与封面，不保证原 EPUB 文件。多模态请求结构已测试，实际提供商能力须设备验收。
- 真实资料不得作为测试夹具；安装前保留旧备份，不删除应用。测试通过不等于真实设备迁移验收完成。
