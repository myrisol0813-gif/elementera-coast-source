# Unified Coast transfer v1 (draft)

Exact UTF-8 payload_json checksum, common across Android/JS. Origin edition and workspace are metadata; destination controls persistence. Initial cloud adapter: chats and calendar. 64 MiB archive limit, 8 MiB cloud import limit, 90 statements per atomic import. No hidden truncation, no replacement of existing IDs; preview classifies existing and blocked records. Unsupported modules remain explicit. Attachments and cross-window snapshot links block the corresponding chat rather than silently losing references. Daily/profile adapters and local restore/UI remain to be completed. Existing readable exports remain independent. No secrets from credential storage, no deployment or real-data writes during this draft.
