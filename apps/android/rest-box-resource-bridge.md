# Rest box native resource bridge (not wired)
The canonical resource source is apps/web/elementera-mcp/deploy-pages/public/rest-box/art/v1.
The future Android build should copy **only** that directory into generated assets under rest-box/art/v1, with a Gradle Sync task and declared input/output. Do not copy the JS lab or maintain a second editable asset tree. The existing app build.gradle.kts is concurrently changed by dream tide PR #92, so this branch intentionally does not change it yet.
RestArtRepository reads the same index and appearance definitions; RestAppearance/RestHousehold mirror the Web version-1 wire format. JVM tests consume canonical files from the source tree. Native actual SVG rendering, masks, CSS/SMIL motion, theme UI and archive integration are not implemented by the loader. A plain Android vector drawable cannot preserve all SVG filters/animations; evaluate a native rendering adapter rather than silently replacing the artwork or falling back to a WebView.
