# 本机模型箱 V2 · 预览验收

本机模式新增多个 HTTPS OpenAI-compatible API 供应商，支持名称、Base URL、Key、手动模型 ID、模型目录获取、真实回复测试及 OpenRouter Key 限额查询。Keystore AES-GCM 加密凭据；不接受明文 HTTP、不跟随重定向、不将 Key 放入普通导出或云端。余额查询仅说明实际返回字段。ChatGPT 套餐复用已有授权与推理，使用独立本机账号存储、本机文本上下文与本机历史。尚未验证真实账户资格或付费调用。两条路径都只发送近期文本上下文；记忆、工具、附件、现实注入和自动思维壤尚未迁移。无模型时仍可仅保存文字。

验收：先测试无网开屏和卸载提示；进入本机模型箱，使用自己的测试 Key 添加供应商，获取目录，选择模型，发送真实文字、停止、重试、重开；测试失败 Key 不导致退出本机、不回退云端。切换前后端验证配置与账号隔离。OpenRouter 普通 Key 限额和账户总余额区别。ChatGPT 登录测试需要用户授权；不得使用真实凭据自动验收。全局 JSON/HTML 明确提示阶段性范围，不称完整备份。PWA 导出字段与完整 ZIP 恢复另做专项对齐。双向同步不在范围内。
