# 本机模式（Source Android）第一阶段

开屏标语下两个圆角气泡：本机模式 / 前后端模式。前后端模式保留已有口令及参观入口；本机模式无需口令，使用独立应用私有文件存储。当前为本机记录预览，不调用模型；未接入功能明确拒绝，不回退网络。支持窗口管理、文字历史、检索、手动日记与动态、阶段性导出。无同步，不改变任何 Web 或服务器部署。

本机验收：无网进入，写入测试记录和日记，关闭进程后重新打开，记录仍在；屋主设置 → 账户 → 返回开屏，切回前后端模式，仍可用参观口令；再次进入本机应保留原数据且不混入参观/在线内容。Source QA APK 仍使用独立应用 ID 与现有签名流程。

此版本仅为第一阶段，不宣称本机模型、记忆、思维壤、附件等完整实现。
